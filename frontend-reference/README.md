# Front-End Reference Library

This library is a learning aid for the WDD 130 workspace. It collects small HTML and CSS examples, component patterns, standards, and prompts that help a student understand front-end development and work effectively with Copilot.

## How to use it

1. Read the explanation before copying an example.
2. Adapt only the part that applies to your current assignment.
3. Keep assignment work in the weekly folders, not in this reference library.
4. Ask Copilot for a hint or review before asking for a correction.
5. Check platform details against MDN when browser behavior or an API is involved.

The code examples are intentionally small. They are reference patterns, not complete assignment solutions or a production design system.

## Sections

- [HTML](html/) - semantic structure, forms, tables, navigation, images, and accessibility.
- [CSS](css/) - foundational reset, typography, variables, Flexbox, Grid, and responsive rules.
- [Components](components/) - partial, reusable patterns for common interface pieces.
- [JavaScript](javascript/) - introductory concepts for later coursework.
- [Patterns](patterns/) - problem-solving outlines for common front-end tasks.
- [Standards](standards/) - coding, accessibility, SEO, and performance practices.
- [AI](ai/) - Copilot instructions, learning prompts, and review checklists.

## Reference sources

[MDN Web Docs](https://developer.mozilla.org/) is the primary external reference for web platform behavior. Use the specific MDN links in each topic file to verify element semantics, CSS properties, JavaScript APIs, accessibility practices, and browser compatibility.

MDN explains how the platform works. The repository instructions still determine the appropriate level of help for course assignments.

## Scope

This library follows the repository's beginner-friendly rules:

- Use semantic HTML and readable CSS.
- Prefer simple Flexbox and Grid examples when they match the lesson.
- Keep HTML, CSS, and JavaScript separate.
- Do not introduce frameworks unless a course requires one.
- Do not turn reference examples into completed student assignments.
