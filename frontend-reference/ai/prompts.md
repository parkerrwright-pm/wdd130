# Learning Prompts

Use these prompts to ask Copilot for help without giving away the assignment.

## Start an assignment

> Read the assignment requirements and rubric. Explain what I am building, list the requirements, identify the HTML/CSS concepts, and give me one next step. Do not write the complete solution.

## Ask for a hint

> I am working on [describe the step]. Ask me one question that will help me decide what to try next. Do not show the answer yet.

## Check an MDN topic

> Explain how [HTML element/CSS property/JavaScript API] works at my course level. Consult the relevant MDN page, link it, and show only a small example unrelated to my assignment.

## Debug code

> Here is the error and the relevant code. Explain what the error means, suggest one debugging check, and let me try before showing a correction.

## Review work

> Review this code against my requirements. First identify what works, then give me one or two issues to investigate. Check semantics, accessibility, layout, responsive behavior, and readability.

## Check accessibility

> Review this HTML for basic accessibility. Use the relevant MDN guidance, explain why each issue matters, and give me a short checklist rather than rewriting the page.

## Use a component reference

> Use `frontend-reference/components/[component]/README.md` as a pattern reference. Help me adapt the idea to my page without generating the complete assignment file.
