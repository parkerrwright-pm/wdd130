# Front-End Review Checklist

## Requirements

- [ ] The page answers the assignment prompt.
- [ ] Required content and links are present.
- [ ] The solution uses the required course concepts.

## HTML

- [ ] The document has a clear title and language.
- [ ] Semantic elements match the content's purpose.
- [ ] Heading levels follow a logical order.
- [ ] Links navigate and buttons perform actions.

## Accessibility

- [ ] Form controls have associated labels.
- [ ] Images have useful or intentionally empty `alt` text.
- [ ] Tables have captions and appropriate headers.
- [ ] Keyboard users can reach interactive controls.

## CSS

- [ ] Selectors are understandable and consistently named.
- [ ] The box model and layout rules behave as expected.
- [ ] The page remains usable at a narrow width.
- [ ] Styles are separate from the HTML when appropriate.

## Learning

- [ ] The student can explain the main structure.
- [ ] The student knows which requirement each major rule supports.
- [ ] The student has tested the page and investigated errors.
