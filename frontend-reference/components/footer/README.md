# Footer

Use a footer for information about the page or its related section, such as
contact details, supporting links, or copyright information. It marks the end
of a page, like credits at the end of a movie. See [MDN `<footer>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/footer).

## Course guidance

- Give the footer a background color that is not used elsewhere on the page.
- Avoid pure black and pure white. Use a near-black, near-white, or muted color.
- Use a muted light footer color when a page has many bright colors.
- Use a light footer color when a page is mostly dark.
- Use a darker footer color when a page is mostly light.
- Add enough padding that the footer clearly denotes the end of the page.
- Keep footer text and links readable against its background.

The example uses `#242321`, a dark gray from the instructor example. Other
course-approved options include `#cdcdcd`, `#414141`, and `#eff1f0` when they
fit the page's existing colors.

For advanced footer ideas beyond WDD 130, read [LogRocket footer design best practices](https://blog.logrocket.com/ux-design/website-footer-design-practices/) and [Fuzzy Math footer best practices](https://fuzzymath.com/blog/footer-best-practices/).
