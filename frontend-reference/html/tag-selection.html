HTML Tag Selection

Choose the element that describes the content. Do not add wrappers unless they provide structure or a styling target you actually need.

Core rules

  • Put text inside a text element such as a paragraph, heading, link, or list item. Do not leave text directly in `body`, `header`, `nav`, `main`, or `footer`.
  • Use `div` only after checking for a more meaningful element.
  • Images normally do not need an extra wrapper. Use `figure` and `figcaption` when a caption belongs with an image.
  • Do not use heading elements or formatting elements to change how text looks. Use CSS; use `span` only to style part of text.
  • Do not use `b`, `u`, `strong`, `em`, or `i` for WDD 130 text styling.
  • Do not use obsolete elements, including `acronym`.

Layout and navigation

Use Grid for major layout areas and Flexbox inside Grid areas when it helps arrange related items.

Use `nav` for navigation. Do not automatically add `ul` and `li`; direct links are appropriate for many navigation areas. Complex navigation may use `div` when it needs a styling or layout grouping.

Class reference elements

Start with elements for page structure: `html`, `head`, `body`, `header`, `main`, `nav`, `section`, `article`, `aside`, and `footer`.

Use text elements for content: `h1` through `h6`, `p`, `a`, `span`, `address`, `blockquote`, `br`, and lists with `ul`, `ol`, `dl`, and `li`.

Use image elements together: `img`, `figure`, and `figcaption`. Use table elements only for data: `table`, `caption`, `thead`, `tbody`, `tfoot`, `tr`, `th`, and `td`.

Use form elements only in forms: `form`, `fieldset`, `label`, `input`, `select`, `textarea`, and `button`. Use `iframe` only for the Week 5 contact-page map, and use `svg` only when an SVG image is required.

Ask before adding a tag

Ask what content the element describes, whether it is required by the assignment, and whether an existing parent already provides the needed structure.

Check [MDN HTML elements](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements) and the [Tutorial Republic HTML5 tag list](https://www.tutorialrepublic.com/html-reference/html5-tags.php) when you are unsure which current element fits.

Use only course-approved elements and ask the instructor when unsure.
