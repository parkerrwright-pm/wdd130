# Responsive Page

## Problem

A page should remain readable and usable when the viewport changes width.

## Approach

1. Start with a simple single-column layout.
2. Use flexible widths and responsive images.
3. Add a media query when the content needs a second layout.
4. Test both a narrow and a wide viewport.

Use [MDN responsive web design](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design) and [MDN media queries](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_media_queries).

## Common mistakes

- Fixed widths that force horizontal scrolling.
- Text that becomes too small to read.
- Hiding important content on small screens.
