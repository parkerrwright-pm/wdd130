# Accessibility Standard

Build pages that can be understood and operated by more people.

- Use semantic elements before adding ARIA.
- Keep headings in a logical order.
- Give every form control a visible label.
- Use useful `alt` text for informative images and `alt=""` for decorative images.
- Make interactive controls keyboard accessible.
- Use sufficient color contrast and do not communicate meaning with color alone.

Read [MDN accessibility](https://developer.mozilla.org/en-US/docs/Web/Accessibility) and [MDN ARIA](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA) when a question goes beyond these fundamentals.
