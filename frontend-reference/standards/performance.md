# Beginner Performance Standard

- Use appropriately sized images and include `width` and `height` when known.
- Avoid unnecessary JavaScript and libraries.
- Keep CSS selectors and page structure understandable.
- Test the page on a narrow viewport as well as a wide one.
- Do not optimize before identifying a real problem.

See [MDN web performance](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Performance) for deeper guidance.
