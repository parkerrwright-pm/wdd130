# Basic SEO Standard

For beginner pages, focus on accurate structure rather than tricks.

- Give each page a specific, useful `<title>`.
- Use one clear primary heading.
- Write meaningful link text.
- Use descriptive image `alt` text when images carry meaning.
- Use descriptive headings that match the content.
- Add a viewport meta element for responsive pages.

See [MDN HTML metadata](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/meta) for platform details.
