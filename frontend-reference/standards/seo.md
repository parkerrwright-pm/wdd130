# Basic SEO Standard

For beginner pages, focus on accurate structure rather than tricks.

- Start the `<head>` with character encoding, then the viewport meta element, then the page title. Put all other head elements after those three.
- Give each page a specific, useful `<title>`.
- Use one clear primary heading.
- Write meaningful link text.
- Use descriptive image `alt` text when images carry meaning.
- Use descriptive headings that match the content.
- Write a descriptive, page-specific meta description of 50-160 characters. Make each description unique to its page, and add it only when the assignment requires it.
- Do not add the retired `x-ua-compatible` Internet Explorer meta tag.

See [MDN HTML metadata](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/meta), the local [head template](../html/head.html), and the instructor-recommended [HEAD reference](../external/HEAD/README.md) for platform details.
