Task3: Nesting Block in Inline

Try placing a
<div>
inside a <span> element.

What error or layout issue do you see? It introduces a block element inside an inline element. This is not allowed in HTML because block elements are meant to take up the full width and cannot be nested inside inline elements. Why does this happen? Because inline elements are not designed to contain block-level elements, and doing so violates the HTML content model.
